# Labs M1 — Processamento de Imagens

Repositório com as atividades práticas da M1 da disciplina de **Processamento de Imagens – 2026**.

Os laboratórios foram desenvolvidos em **Python**, utilizando execução por linha de comando e testes automatizados.

## Laboratórios

### M1.1 — Operações básicas

Implementação de operações básicas de processamento de imagens:

- Inspeção de imagens;
- Cópia;
- Extração dos canais R, G e B;
- Conversão para escala de cinza por média;
- Conversão para escala de cinza ponderada;
- Quantização de imagens.

📁 Pasta: `lab_m1_1_joao_brasil_e_luis_ribeiro`

### M1.2 — Operações ponto a ponto

Implementação de operações de transformação de intensidade:

- Brilho;
- Contraste;
- Negativo;
- Limiarização;
- Histograma;
- Testes com imagens sintéticas e imagens de teste.

📁 Pasta: `lab_m1_2_joao_brasil`

### M1.3 — Operações por vizinhança

Implementação de operações utilizando convolução e vizinhança:

- Convolução genérica;
- Filtros de média 3×3 e 5×5;
- Média ponderada;
- Laplaciano;
- Realce utilizando Laplaciano;
- Sobel Gx e Gy;
- Magnitude aproximada e Euclidiana;
- Estratégias de borda `copy` e `replicate`.

📁 Pasta: `lab_m1_3_joao_brasil`
